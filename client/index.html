Policy Scope (HDFC ERGO Private Car)

The agent is grounded in the public HDFC ERGO Private Car Package Policy wording (text-layer PDF in corpus/).

  • Section I: Own damage from accidental external means, burglary, housebreaking, fire, and flood.
  • Section II: Legal liability to third parties for bodily injury and property damage.
  • Limitations as to Use: Private carriage only. Strictly excludes usage on hire, reward, and commercial delivery.
  • General Exclusions: Consequential loss, depreciation, mechanical/electrical breakdown, and driving while intoxicated.

Multi-Provider Model Architecture

The intake and research planning loop supports dual model providers configured via environment variables:

  • Local Model: Qwen2.5 1.5B served via local llama.cpp OpenAI-compatible endpoint (zero API key needed).
  • Google Gemini: Frontier Gemini model integration (gemini-2.5-flash) using Google Gen AI SDK.
  • Deterministic Stub: Delayed reproducible test harness for automated system regression suites.
  • Independent Verifier: Separate worker checking exact PDF quotes and entailment before any advice is shown.
