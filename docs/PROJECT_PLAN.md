# Evaluation 1: corpus confirmation and project plan

## Problem and boundaries
Accept a private-car FNOL; validate it before execution; retrieve apparent cover
and modifying restrictions; propose a coverage position and operational queue;
have an independent verifier resolve the citations. A human always decides.
No settlement calculation, training or cloud hosting.

## Corpus proposed for faculty confirmation
Insurer: HDFC ERGO. Product: Standard Form for Private Car Package Policy.
The supplied official PDF contains an insurer FAQ/claims procedure on PDF page 1
and complete wording/endorsements on PDF pages 2-9. The claims page is part of the
same published document, not an independently downloaded second publication.
Confirm that this satisfies the two-document expectation; otherwise replace the
claims excerpt with a separately published procedure before Evaluation 1.

Source and retrieval date are in corpus/SOURCES.md; hashes and exact page/chunk
references are generated by indexing. This is a historical teaching snapshot,
not proof of present-day policy terms. The insured's schedule is unavailable.

## Reference case to confirm
Input: "I was making a food delivery run in my own car when the accident happened."
Use the normal personal-use structured value deliberately: narrative must still
trigger the concern. Expected class: own_damage. Queue: investigation.
Position: coverage_concern, not an approval/rejection.

Evidence: PDF p2 Section I accidental-external-means cover; PDF p1 FAQ's
hire/reward exclusion; PDF p3 General Exception 3(a), referring to Limitations
as to Use. The schedule-specific permitted-use definition is not supplied.
Therefore the defensible reference answer flags a potential restriction and
requests schedule/endorsement review rather than asserting all delivery is
definitively excluded. See corpus/reference_answer.json for extracted passages.

Test values: IDV 500000; repair estimate 12000; network garage true; licensed true;
intoxicated false; India; loss within the policy period. Control: same values,
ordinary parking collision, expected fast-track recommendation. Operational
fast-track threshold 20000 is a configurable demo choice, not an insurer rule.
